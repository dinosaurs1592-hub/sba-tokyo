# SBA Tokyo 完成ロードマップ

> 改訂: 2026-05-03(2 値判定 + Object 面車モチーフ確定 + キャラ性能差延期)

## ゲームのビジョン

東京の街を舞台にした **3レーンスケート縦スクロール・アーバンアクション**。  
**Jet Set Radio** 風のセルシェード美学と、ミニオンラッシュ的なメタゲーム体験を融合。  
スピードを維持しながら **着地時の入力タイミング** に応じてコンボを繋ぎ続ける緊張感がコアバリュー。

詳細仕様:
- ロジック: [`docs/specs/core_spec.md`](../specs/core_spec.md)
- 体験/メタゲーム: [`docs/specs/game_design.md`](../specs/game_design.md)

## フェーズ2: MVP(コア体験成立) 🔄

**目標:** **JSR 風 3レーン走行 + 着地リズムゲーム** が単発走行で楽しめる状態にする。  
完成基準: [`core_spec.md`](../specs/core_spec.md) §12 を全項目満たす。

### M5: 着地タイミング視覚フィードバック

- バッファ済入力を画面エッジフラッシュで通知(空中で「準備完了」サイン)
- Perfect 着地でゴールド演出 + コンボ数字バウンス
- バッファ失効時(0.5s 経過)に小さなフェードアウト演出

### M6: 先行入力バッファ方式(コア哲学の柱・2 値判定)

- `PlayerState.LandingWindow` を廃止し、空中入力を `inputBuffer` に蓄え、着地時に評価
- `SBAInputManager` から生スワイプイベント発行(方向 + 角度)
- `RunnerController` 側でバッファ生存時間 0.5s を管理
- 着地評価は **バッファ存在 = Perfect、なし = Miss** の 2 値(Good ティア廃止)
- `RegisterLandingResult()` の `elapsedSinceLanding` は常に 0 で渡す(将来削除)

### M7: スライドジャンプ(斜め上スワイプ)

- 入力方向の角度 30°〜60° で発火
- レーン変更 + Y初速 同時付与
- `LandingActionType.SlideJump` 追加

### M8: チャンク式生成

- `ChunkSpawner` 実装、`ChunkController` で entry/exit 管理
- チャンク種別 6 種(`ChunkFlat` / `ChunkObstacleRun` / `ChunkRailSection` / `ChunkObjectPlatform` / `ChunkMixed` / `ChunkGap`)
- オブジェクトプーリング

### M9: 難易度スケーリング

- `DistanceTravelled` に応じて 障害物密度 / 速度減衰 / 最高速 を補正
- `core_spec.md` §7.3 の表に従う

### M10: オーディオ基盤

- `AudioManager` シングルトン
- 基本 SFX 5 種(プッシュ / 着地 Good / 着地 Perfect / コンボリセット / ゲームオーバー)
- BGM 1 曲(JSR 風フリー素材)

### M11: 穴落ち判定

- `ChunkGap` 着地時に床なしで `TriggerGameOver()`
- 穴の出現は 200m 以降に解放

### M12: コンボタイムアウト

- `comboTimeoutSeconds = 3.0` で最終入力からカウント
- タイムアウト時に `ComboCount = 0`

## フェーズ3: メタゲーム(定着要素) ⬜

**目標:** リテンションが発生するメタゲーム基盤を構築。  
完成基準: 1 走行で平均 30–50 コイン獲得、デイリーミッション 3 つが揃う。

### M13: コイン経済 + 収集

- 走行中のコイン配置(レーン上に並ぶ)
- 取得 SFX + UI ポップ
- `Coins` を `PlayerPrefs` に永続化

### M14: シールド + パワーアップ基盤

- `ShieldComponent` 実装(衝突 1 回耐久)
- 走行中レアアイテム配置
- 開始前購入 UI(ショップから)

### M15: リバイブ

- ゲームオーバー画面に「リバイブ」ボタン
- コイン 50 枚消費(動画広告は SDK 統合後)
- 倒れた地点 5m 後方 + Speed 24.0 + シールド付与で復活

### M16: ミッション(デイリー)

- 3 つのデイリーミッション生成(易・中・難)
- 24:00 リセット
- メインメニューに進捗表示

### M17: キャラクター + アンロック(性能差なし)

- 5 体のキャラを実装(全キャラ **同性能**、見た目のみ差別化)
- アンロック条件:コイン or ミッション報酬
- コスチューム 2–3 着 / キャラ
- ステータス差はフェーズ4 で再評価(`game_design.md` §6.1 参照)

### M18: メインメニュー / 設定 / データ永続化

- メインメニュー UI(キャラ選択 / ミッション / ショップ / 設定 / スタート)
- 設定画面(ハプティクス / 音量 / カメラ感度 / 言語)
- `PlayerPrefs` キー設計を `game_design.md` §14 に従って実装

### M19: チュートリアルモード

- 任意起動の隔離マップで 7 ステップ
- 完走で 100 コイン + 称号付与

## フェーズ4: 派手アクション + 完成度仕上げ ⬜

**目標:** **JSR 級のスタイリッシュさと中毒性** を実現。

### M20: SS ジャンプ(L字 / V字 認識)

- スワイプ軌跡サンプリング + 角度変化点検出
- 失敗時は通常スライドジャンプにフォールバック
- `LandingActionType.SuperSlideJump` 追加

### M21: ボードトリック(下スワイプ版)

- F キー固定を廃止、Grinding 中の下スワイプで発火
- トリック種別の追加(キックフリップ等)

### M22: オートドライブモード

- コンボ 20 で突入、8s 持続、無敵 + 最高速固定
- **スコア倍率 2.0x 固定**(タップで増減なし)
- **中タップでコンボ +1**(JSR 風グラフィティ展開演出)
- 終了時コンボ継続、倍率 1.0x にリセット

### M23: 俯瞰カメラ切替(革新枠・偵察モード)

- HUD 右下のボタンで切替
- **俯瞰中はキャラ操作すべて不可**(プッシュ/レーン/ジャンプ/タップ全て封じる)
- **速度通常減衰、衝突は通常通り発生**(ゲームオーバー直結)
- 用途は「先のチャンクパターン偵察」のみ。長時間維持は速度低下で自殺行為

### M24: ハプティクス + 設定切替

- 6 種類のイベントに振動割り当て
- 設定画面で ON/OFF

### M25: JSR 風セルシェードシェーダー + ビジュアル仕上げ

- セルシェードシェーダー(URP Shader Graph)
- アウトラインポストプロセス
- 3D 環境アセット(渋谷風スクランブル) — **Blender + MCP で制作**
- Object 面の「車」モデル 2–3 種(セダン / タクシー / バン) — **Blender + MCP**
- キャラクターモデル + Animator — **Blender + MCP**
- VFX(スピードライン / 着地フラッシュ / グラインドスパーク)
- **オリジナル BGM 統合**(ユーザー制作音源を受領 → AudioManager に組み込み)

### M26: 失敗演出 + 最終ポリッシュ

- グラフィティ風文字フラッシュ(`WIPEOUT!` / `CRASHED!`)
- iOS / Android ビルド設定
- 60fps 動作確認(低スペック端末)
- アプリアイコン / スプラッシュ画面

## 技術ルール(全フェーズ共通)

- 仕様変更は [`core_spec.md`](../specs/core_spec.md) / [`game_design.md`](../specs/game_design.md) を改訂してから着手
- `PlayerState` / `SurfaceType` / `LandingActionType` の既存値は変更禁止(追加は可)
- `SerializeField` の値はコードにハードコードしない(Inspector で管理)
- 新しいチャンクや面タイプは既存のフレームワークを拡張する形で追加
- 各マイルストーンは [`docs/contracts/`](../contracts/) に契約書を作成してから着手
