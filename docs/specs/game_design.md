# SBA Tokyo — Game Design Specification

> ステータス: **MVP(フェーズ2)に向けた骨格策定中** — 2026-05-03  
> 詳細はフェーズ3 / フェーズ4 で肉付け

本書は **体験/メタゲーム仕様**(コイン経済・ミッション・キャラ・UI・音楽・アート)を扱う。  
ロジック仕様は [`core_spec.md`](core_spec.md)。

---

## 1. デザインピラー

| ピラー | 内容 |
|---|---|
| **アーケード硬派** | SS ジャンプ難、衝突即死、Perfect 厳しい。失敗のフラストレーションが中毒性を生む |
| **メタゲーム盛り** | コイン / ミッション / リバイブ / キャラアンロック でリテンション |
| **JSR 美学** | セルシェード、ストリート、グラフィティ、ファンク。**ビジュアル + 音楽のみ**で表現(メカは純粋走行系) |
| **革新カメラ** | 背面 + 俯瞰切替ボタン。視認性とスピード感のトレードオフ |

---

## 2. コイン経済(フェーズ3)

### 2.1 通貨
- **コイン**(1 種、ソフト通貨のみ)
  - ハード通貨は MVP 範囲外。将来課金 SDK 統合時に検討。

### 2.2 取得源
| 源 | 量 |
|---|---|
| 走行中収集(レーン上に配置) | 1 枚/個 |
| ミッション報酬 | 50 / 100 / 200 |
| デイリーログインボーナス | 検討(フェーズ3後半) |

### 2.3 用途
| 用途 | 価格 |
|---|---|
| リバイブ | 50 コイン |
| シールド購入(走行前) | 30 コイン |
| キャラアンロック | 500–2000 コイン |
| コスチュームアンロック | 200–800 コイン |

### 2.4 経済バランス指針
- 1 走行平均獲得: 30–50 コイン(初心者)、80–150(上級者)
- 1 リバイブ ≒ 1 走行分のコイン消費
- キャラアンロック ≒ 10–40 走行分

---

## 3. リバイブ(フェーズ3)

| 項目 | 仕様 |
|---|---|
| 1 走行あたり | **1 回まで** |
| 消費 | コイン 50 枚 / 動画広告 1 本(SDK 統合後) |
| 復活地点 | 倒れた地点の **5m 後方** |
| 復活時 Speed | `startSpeed` 相当(24.0)に再設定 |
| 復活時コンボ | **維持**(失敗で消えると挫折感が強すぎる) |
| 復活時シールド | 自動付与(タイマー無敵)5.0s(§4 と同仕様) |

---

## 4. シールド(フェーズ3)

| 項目 | 仕様 |
|---|---|
| 効果 | 持続中の衝突をすべて無効化(複数回衝突でも消費されない) |
| 入手 | 走行中レアアイテム / 開始前購入(30 コイン) / リバイブ時自動 |
| 持続 | **タイマー型 5.0s**(`shieldDuration = 5.0`、§3 リバイブと統一) |
| 上限 | 同時起動 1 枚まで(起動中の追加取得は時間延長 +5.0s) |
| 視覚 | キャラ周囲に半透明バリア + 残り時間バー |

> 他のパワーアップ(マグネット / x2 スコア等)は MVP 範囲外。フェーズ3 後半に検討。

---

## 5. ミッション(フェーズ3)

### 5.1 種類
- **デイリーミッション**: 毎日 3 つ提示、24:00 リセット

### 5.2 例
| ミッション | 報酬 |
|---|---|
| 1 走行で コンボ 20 達成 | 50 コイン |
| 1 走行で 距離 500m 到達 | 50 コイン |
| 累計 コイン 100 枚獲得 | 100 コイン |
| 1 走行で Perfect 着地 5 回 | 100 コイン |
| グラインド累計 200m | 50 コイン |
| SS ジャンプ 3 回成功 | 200 コイン |

3 つの組み合わせは難易度バランス(易・中・難)で構成。

### 5.3 表示
- メインメニューに進捗バー表示
- 走行中も画面隅に小さく進捗表示

## 6. キャラクター / コスチューム(フェーズ3)

### 6.1 キャラクター
- **初期**: 1 体(デフォルト・無料)
- **アンロック**: 4 体(コインまたはミッション報酬)
- **ステータス差**: **MVP / フェーズ3 では実装しない**(全キャラ同性能)
  - 性能差の詳細はフェーズ4 で再評価(下記表は将来の参考案)

> 参考案(フェーズ4 で再検討、現時点では確定しない):
> | キャラ | 性能差 | 特徴 |
> |---|---|---|
> | デフォルト | なし | バランス型 |
> | スピード型 | TBD | 高速寄り |
> | パワー型 | TBD | 加速寄り |
> | バランス改 | TBD | 汎用上位 |
> | 特殊型 | TBD | 特殊効果(具体内容は後日決定) |

### 6.2 コスチューム
- 各キャラに 2–3 着
- **見た目変化のみ**(ステータスに影響なし、フェーズ4 でステータスが入っても変わらない)
- アンロック価格: 200–800 コイン

### 6.3 ビジュアル方向
- JSR 風アニメ調
- インラインスケート装着
- ヘッドフォン、グラフィティスプレー(背景小物)

## 7. UI / UX

### 7.1 言語
- **日英混淆スタイル**(JSR 流の看板的演出)
- 例: `COMBO 10` / `距離 100m` / `SHIELD 1` / `WIPEOUT!`
- メニュー画面の主要ラベルは英語、補助テキストは日本語

### 7.2 HUD(走行中)
- 左上: スコア + コンボ
- 右上: 距離 + 速度
- 中央下: シールド残数 + リバイブアイコン
- 右下: **俯瞰切替ボタン**
- 中央: ルールメッセージ(`LastRuleMessage`)、コンボ達成時バウンスアニメ

### 7.3 メインメニュー
- キャラ選択
- ミッション一覧
- ショップ(キャラ/コスチューム)
- 設定
- チュートリアルモード
- スタート

### 7.4 失敗演出
- JSR 風グラフィティ風文字フラッシュ:`WIPEOUT!` / `CRASHED!`
- リバイブ提案ダイアログ(コイン残数 / 動画広告)

## 8. カメラシステム

### 8.1 基本: 背面カメラ
- 三人称背面追従
- カメラ位置: キャラ後方 5m、上方 2.5m
- FOV: 60°
- 追従ラグ: 0.1s(`SmoothDamp`)
- シェイク: 衝突時 0.3s 強度 0.5

### 8.2 俯瞰カメラ切替(革新枠)
- HUD 右下のボタンタップで切替
- 俯瞰位置: キャラ上方 12m、背面 3m、見下ろし角 70°
- FOV: 50°
- **挙動制約(タイムアウト型偵察モード)**:
  - 俯瞰中はキャラ操作 **すべて不可**(プッシュ / レーン移動 / ジャンプ / タップ全部受付ない)
  - 速度は **通常通り減衰**(俯瞰中も `idleDecayDelay` 経過後に減衰開始)
  - **障害物衝突は通常通り発生**(ゲームオーバー直結)
  - コイン取得は自動継続(物理接触で取得)
  - 距離スコアは通常通り加算(コンボ・着地スコアは事実上発生しない)
- **使い方:** 先のチャンクパターンを瞬時に偵察するための一時表示。長時間維持は速度低下/衝突リスクで自殺行為。
- **トレードオフ:** 視認性 ↑ / 操作性ゼロ + 衝突リスク継続
- 切替演出: 入切ともに 0.2s でスムーズに視点遷移

### 8.3 オートドライブ中
- 自動的に背面カメラに固定(俯瞰切替ボタン無効化)
- カメラがゆっくり回り込む派手演出

## 9. ハプティクス(設定で切替)

| イベント | 強度 | 時間 |
|---|---|---|
| Perfect 着地 | 中 | 0.05s |
| 衝突 / ゲームオーバー | 強 | 0.2s |
| シールド発動 | 中 | 0.1s |
| ボードトリック | 弱 | 0.03s |
| オートドライブ突入 | 強 + パターン | 0.3s |
| オートドライブ中タップ | 弱 | 0.02s |

設定画面で **ON / OFF** 切替可能。デフォルト: **ON**

## 10. アート(JSR モチーフ)

### 10.1 基本方針
- **セルシェードシェーダー**(URP Shader Graph で実装)
- 太い輪郭線(`Outline` ポストプロセス)
- 原色配色(赤・黄・青・緑)
- グラフィティ要素は **背景演出のみ**(ゲーム関与なし)
- **3D アセット制作: Blender + MCP 連携**(claude-code 経由で Blender を駆動して生成・編集)

### 10.2 ステージ環境(架空東京)
- 渋谷風スクランブル → `Stage_Shibuya`
- 秋葉原風電気街 → `Stage_Akiba`(フェーズ4)
- 新宿風高層街 → `Stage_Shinjuku`(フェーズ4)
- 共通要素: 看板、ネオン、グラフィティ壁、自動販売機、電車高架
- **Object 面の主モチーフは「車」**(走行レーンに配置されたセダン/タクシーなどに飛び乗る)

### 10.3 MVP のアートスコープ
- ステージ 1 種(`Stage_Shibuya`)
- キャラ 1 体(デフォルト)
- 障害物プレハブ 5 種程度
- **Object 面用「車」モデル 2–3 種**(セダン / タクシー / バン)
- セルシェードシェーダー基本実装
- Blender MCP ワークフロー確立(モデル生成 → Unity import → セルシェード適用)

## 11. 音楽 / SFX

### 11.1 BGM 方向性
- **ファンク / ブレイクビーツ / 渋谷系混合**(JSR 直系)
- ループ可能、走行中は常時再生
- オートドライブ中は **音量 +20% / フィルター解放**

### 11.2 SFX(M9 オーディオ基盤と連動)

| イベント | 音 |
|---|---|
| プッシュ | 蹴り音(短い) |
| 着地成功 Good | ヒット音(低め) |
| 着地成功 Perfect | ヒット音(高め・明るい) |
| コンボ +1 | ピッチ上昇 SFX(コンボ数で音程変化) |
| コンボリセット | 低い SFX |
| ボードトリック | シャリン音 |
| シールド発動 | バリア展開音 |
| オートドライブ突入 | 派手なホーン |
| 衝突 / ゲームオーバー | 重い衝突音 |

### 11.3 MVP 音源調達
- **BGM: ユーザー(プロジェクトオーナー)が制作**
  - 開発の **大半が完成した段階で渡される**(終盤統合)
  - 開発中は **無音 or プレースホルダー音源**(フリー素材を仮置き)で進行
  - 開発フローを音源に依存させない
- SFX: フリー素材(freesound.org 等)
- 将来オリジナル SFX 委託も視野(フェーズ4 後半)

## 12. チュートリアル(任意モード、フェーズ3)

### 12.1 起動
- メインメニューから **任意で起動**(本編強制なし)
- 完了状況をローカル保存(再生時にスキップ可)

### 12.2 段階(7 ステップ)
1. プッシュ(下フリック / S)
2. レーン移動(左右スワイプ)
3. ジャンプ(上スワイプ)
4. **先行入力タイミング**(空中で次のアクションを入力 → 着地で Perfect)
5. グラインド(レール接触)
6. ボードトリック(下スワイプ)
7. SS ジャンプ(L字 / V字)

各ステップは隔離された訓練ゾーンで実施(チャンク生成は使わず固定マップ)。

### 12.3 報酬
- 完走時: 100 コイン + 「初級ライダー」称号

## 14. データ永続化

**`PlayerPrefs` を使用**(オフラインゲームのため十分)

| キー | 型 | 内容 |
|---|---|---|
| `BestScore` | int | ハイスコア |
| `BestCombo` | int | 最大コンボ |
| `BestDistance` | float | 最長距離 |
| `Coins` | int | コイン保有数 |
| `UnlockedChars` | string(JSON 配列) | アンロック済キャラ ID |
| `UnlockedCostumes` | string(JSON 配列) | アンロック済コスチューム ID |
| `MissionsState` | string(JSON) | デイリーミッション進捗 |
| `LastMissionReset` | string(ISO 日時) | 最終リセット時刻 |
| `Settings` | string(JSON) | 設定一式 |
| `TutorialCompleted` | bool | チュートリアル完了フラグ |

> 暗号化なし(オフライン専用、セキュリティ要求なし)
