# SBA Tokyo フェーズ2 GDD — SBA Tokyo コア

> ステータス: **策定中**（フェーズ1完了後に着手）

## 目的

プロトタイプの骨格に「SBA Tokyo らしさ」を乗せる。着地ウィンドウ・コンボ・面別ルール・チャンク生成を完成させ、ゲームとして成立させる。

---

## コアループ（完成形）

```
走る → 障害物を認識 → レーン変更 or ジャンプ
  → 着地ウィンドウが開く（視覚フィードバック）
  → 正しいアクション入力 → コンボ継続・スピードボーナス
  → 外れたらコンボリセット
  → スピードが尽きるかぶつかるとゲームオーバー
```

---

## 機能仕様

### M5: 着地ウィンドウ 視覚フィードバック

**目的:** プレイヤーが「今が入力タイミング」と直感できるようにする。

| 状態 | フィードバック |
|---|---|
| 着地ウィンドウ開放 | 画面エッジを白くフラッシュ（0.15s） |
| Perfect タイミング | 画面エッジをゴールドにフラッシュ（0.08s） |
| コンボ継続 | コンボ数字をバウンスアニメーション |
| コンボブレイク | コンボ数字を赤くフェード |

実装方針：
- `PrototypeHUD` に `Image` コンポーネントを追加し `alpha` アニメーション
- `PrototypeGameManager` に `LandingSuccess` / `LandingFailed` イベントを追加
- `PrototypeHUD` がイベントを購読してフラッシュ制御

---

### M6: スライドメカニクス

**目的:** 空中での下スワイプを「早期着地＋着地アクション」として機能させる。

ルール：
- 空中で下スワイプ → `Sliding` モーション開始（将来的にアニメーション）
- 着地時に `Swipe` アクションとして評価される
- Ground / Rail では成功、Object では失敗（Tap のみ有効）

`PrototypeLandingActionType` への追加不要（`Swipe` を流用）。  
`PrototypeInputManager` に「空中かどうか」の判定を追加する。

---

### M7: 難易度スケーリング

**目的:** 距離に応じて難易度が上がり、上限がないスコアへの意欲を生む。

| 距離 | 変化 |
|---|---|
| 0〜200 m | 基本設定のまま |
| 200〜500 m | 障害物密度 +20%、速度減衰 +0.5/秒 |
| 500 m〜 | 障害物密度 +40%、最高速度上限を 24 に引き上げ |

実装：`PrototypeGameManager.Update()` に `DistanceTravelled` に応じたパラメータ補正を追加。

---

### M8: チャンク式レベル生成

**目的:** ランダム単障害物から、意図されたパターンへ。

チャンク種別（最低5種）：

| チャンク | 内容 |
|---|---|
| `ChunkFlat` | 平坦な道路、障害物なし（息継ぎ） |
| `ChunkObstacleRun` | 3レーンに障害物パターン |
| `ChunkRailSection` | レール面を含む区間（グラインド可能） |
| `ChunkObjectPlatform` | 段差オブジェクト面（ジャンプして Tap 着地） |
| `ChunkMixed` | レール + 障害物の組み合わせ |

実装方針：
- `ObstacleSpawner` を `ChunkSpawner` に置き換え
- チャンクは Unity プレハブで管理
- `ChunkSpawner` はプレイヤーの Z 位置に応じてチャンクを継ぎ足し・回収

---

### M9: オーディオ基盤

**目的:** 音でゲームフィールを強化する最小実装。

| イベント | 音 |
|---|---|
| プッシュ | 足音・蹴り音（短いSFX） |
| 着地成功 | ヒット音（低め） |
| Perfect 着地 | ヒット音（高め・明るい） |
| コンボ継続 | ピッチが上がる短いSFX |
| コンボブレイク | 低いSFX |
| レールトリック | シャリン音 |
| ゲームオーバー | 重い衝突音 |

実装：`AudioManager` シングルトン（`AudioSource` × 4チャンネル程度）。  
`PrototypeGameManager` のイベントを購読。

## 面別着地ルール（確定版）

| 面 | 成功アクション | 失敗 |
|---|---|---|
| Ground | Tap / Swipe / Jump | なし |
| Object | Tap のみ | Swipe / Jump |
| Rail | Tap / Swipe / Jump / RailTrick | なし（グラインド中は常時成功扱い） |

---

## コンボシステム（確定版）

| 条件 | 処理 |
|---|---|
| ウィンドウ内 + 正しいアクション | `ComboCount +1` / `Score +100` |
| Perfect タイミング（0.08s以内） | `Score +200` / `Speed +1.5` |
| ウィンドウ外 / 誤アクション | `ComboCount = 0` |
| 障害物衝突 | ゲームオーバー（コンボ無関係） |
| レールトリック | `ComboCount +1` / `Score +150` |
